## 2. 语义边界

1. **发现与围栏。** 路径、方法、参数与所属域只来自 manifest；应用能力与会话 closure 决定可调用范围。平台名称不是授权，终端声明不是可信用户身份。未知能力不自动降级到旧路径。
2. **通信与完成。** 请求为 HTTP，事件为 SSE；终端工具分块按原 terminal 协议上传和确认。连接成功、HTTP 202、空轮询、SSE EOF 均不是任务完成。`session.ended` 也不是本轮成功。必须区分 `turn.completed`、`turn.aborted`、失败和未知状态。
3. **统一事件。** `EventEnvelope` 恰为七键 `contract/eventId/domain/type/cursorSet/terminalStatus/raw`。五种游标分别管理，事件续订位置不能当档案覆盖、输出水位或材料消费回执。
4. **字节与摘要。** 控制 JSON 严格校验重复键、UTF-8、整数范围、深度/节点/字节帽；canonical 编码、domain 前缀和摘要算法保持原定义。IR/附件等被承诺摘要的正文按原始字节保存和回传，不重编码。业务工具参数及结果中的普通 JSON 不强制改成控制 JSON。
5. **执行与安全。** 先校验身份/会话/工作区/连接代际、绑定、租约、操作摘要，再调用终端注册的 handler。未知副作用不以新键重跑。默认无任意 shell、无 Serve 宿主文件系统回落。
6. **存储与 ACK。** 档案正文、附件、摘要链持久化后才提交 ACK；本地保存不代表 Serve 已受理。失回应恢复并重放原键/原请求，材料 received 不等于核心 consumed。历史存储数据不能自行恢复当前授权。
7. **请求头。** 保留 Idempotency-Key、If-Match、deadline 的 r7 接线；重试不换幂等键、不延长原截止时间。统一码和 retryAction 为主，族码保留在 detail。
8. **职责。** Serve/kernel 继续管理运行、上下文、记忆组织、权限、裁决和用量；Go 是协议与终端能力适配层。Electron 的原集成 SDK/IPC 模式不受本次开发影响。

## 3. 历史文案冲突的处理

上游部分 RFC 的标题和 manifest 状态仍保留 `candidate`、`drafted`、`additive` 等历史标签；本次原样保存，不仅为更改标签就制造 r8 或改变已发布行为。冻结意味着**消费当前完成版本**，不把这些词解释成可在 Go 实现中自行改合同。

具体已核对差异：

- 旧 UAPI RFC 的“If-Match 尚未接线”是历史描述；冻结 r7 manifest 的 `expectedRevision/etagPath/requestIdPath` 和现行三头金样为当前事实。
- 旧手册中的 r6/80 操作不覆盖本次 r7/81 操作。
- 会话创建响应使用 `sessionId`；新建为 201，附着原活体可为 200，不把 200 或 `resumed:false` 判为协议错误。
- `session.ended` 的统一终态投影并不能证明一次消息轮成功。
- 旧 `ClientToolDecl` 的 definitionDigest 采用其原有 JSON 排序语义，不能拿 SDK2 控制 canonical 不加区分地替换。跨语言实现若只能覆盖子集，必须明确拒绝不支持输入并记录缺口。

读取优先级：冻结 manifest 定路由及请求头；各域 schema 定字段和值域；对应 RFC 定 ACK、身份、租约、恢复等跨请求语义；金样锁已承诺字节。上述有明确记录的历史冲突按本节处理。发现新冲突先登记并会签，不靠某一实现静默猜测。

## 4. 漂移门与变更流程

```sh
go run ./internal/gen/contractcheck
go run ./internal/gen/contractcheck -source ../tansr-cli
go run ./internal/gen/manifest2go -check
go test ./...
```

`-source` 接受实际上游检出路径；位于工作树时可传 `J:/tansr/tansr-cli`。默认校验锁内所有副本、manifest 的源文件/金样引用及聚合指纹；测试故意篡改字节、漏文件或路径逃逸均应拒绝。不会联网下载或自动更新合同。

合同变化须单独说明原因、受影响终端与兼容影响，经方案/RFC 会签后更新上游 revision、schema/金样/生成物，再显式更新本冻结清单及消费者。修正 SDK 实现不得顺带放宽合同。参考实现变更触发参考复核，不自动视为 wire 破坏。

本次不修改 Serve、发布版本、弃用窗口或生产配置；不将本地冻结文件误报成所有仓已经完成远端同步。验收与合并事实随 GO-01 执行记录回填。
